# Spectrum

Two daily word games, live at https://henri-cmd.github.io/spectrum/ (Darts, on the sonar console) and https://henri-cmd.github.io/spectrum/spectrum.html (Spectrum).

**Spectrum** is a daily word game. Each day has a category and a hidden answer. Four spectrums (like *tiny ↔ huge*) are revealed one at a time; each guess is marked on its spectrum by where it sits compared with the answer. After four guesses comes a final guess with all four showing. Any word the game knows (200,000 of them) can be guessed.

**Sonar** (the Darts console) is the second game, six rounds a day on one board. The board's two axes are general spectrums fixed for the day (a weakly correlated pair from the twelve in the `random` bank), and every round has its own category, drawn from the specific ones in `puzzles/src/arena-categories.json` (fruit, dog breeds, musical instruments, currencies, pirates… 50-odd, each a list of seed words and an `axes` list of the general spectrums that make sense for it, so colours are never asked small↔big; add a category by adding an entry and rebuilding). The day's pair is dealt only to categories it fits, and the build keeps only pairs that fit at least six. Rounds 1–3 set a random target in different quarters of the board, round 4 the centre bull, round 5 is reversed (you are given a word and tap where it sits), round 6 is the boss (as many words as you can at one target before the clock runs out). Each round has 60 seconds; a word scores 50 on the dot, falling linearly to zero one unit away, plus up to 30 for speed (scaled by the time left), no answer scores nothing, and the day's total is the sum. `build.py` writes `puzzles/arena/`: one shard set with every word's position on all six general spectrums and its fit for each category (how close it sits to the category's nearest seed), and `arena.json` with the spectrum and category names, a per-category fit threshold calibrated leave-one-out on the seeds, the axis pairs and each category's seeds with positions (for reachable targets, the reverse round's word and the end-of-game reveal). The day's axes, category order and targets come from a seeded random generator, so everyone gets the same game.

## Files

- `index.html` + `darts.js` — Darts. `spectrum.html` + `game.js` — Spectrum. No build step; serve the folder over http. Each loads the day's puzzle on its own and they share nothing but the data files.
- `themes.css` — the Darts console look (Graphite). The console is a full-screen submarine command panel drawn in CSS and SVG with no sprites: the scope in the middle with the terminal under it, and Timer, Category, Log, Axis analysis, Manual and Settings screens around it. Two alternates survive behind `?theme=abyss` (near-black) and `?theme=saloon` (the pixel-art bar, whose sprites in `assets/saloon/` are generated by the scripts in `art/`); there is no switcher in the page.
- `puzzles/src/categories.json` — each weekday's category, the seed words that define what fits it, and its bank of spectrums with anchor words.
- `puzzles/src/puzzles.json` — the puzzles: an answer and four spectrums from the category's bank.
- `build.py` — generates `puzzles/<id>/…` and `puzzles/index.json` (the day-by-day schedule).
- `designs.html` — the seven chart designs that were compared when choosing the wheel and star views.

## Running locally

```bash
python3 -m http.server 8000
```

then open http://localhost:8000.

## Rebuilding puzzle data

Needs Python 3 with numpy, and a word-vector file in GloVe/word2vec text format (gzipped is fine). The live data was built with `glove-wiki-gigaword-300.gz` (394 MB, from the gensim-data releases on GitHub), which places words noticeably better than the 100-dimension file.

```bash
python3 -m venv .venv && .venv/bin/pip install numpy
.venv/bin/python build.py --vectors data/glove-wiki-gigaword-300.gz
```

The build prints, for every spectrum, its leave-one-out error over the anchors (lower is better; 0.2 is good, 0.5 is rough) and the words that land at each end. Improve a spectrum by adding anchors: common words from the category with a hand-placed position from −1 to 1.

## Adding a puzzle

Add an entry to `puzzles/src/puzzles.json` (answer must be a single word the vectors know), optionally add spectrums or anchors to `categories.json`, and run the build. Each weekday's category uses its puzzles in order, one per week; the schedule is generated for 120 days from the launch date (`--launch`, `--days`).

## Scoring

Spectrum: `scoreGame()` at the top of `game.js` is the one place the rule lives: the closest guess's mean gap from the answer across the revealed spectrums, mapped to 0–100. Only the exact answer scores 100.

Sonar: `pointsFor()` and `timeBonus()` at the top of `darts.js` (`MAX_POINTS`, `FALLOFF`), with the round list (`KINDS`), the 30-second clock and the target band as constants beside them.
